# VisionInterview 学习闭环与可靠性优化设计

目标：完成优化清单中的 P0–P3 与计时清理，使站点具备到期复习、受控分类、安全备份、AI 稳定降级、有效日志和高频快捷操作。

约束：保留现有导航、主题、题组结束后统一评审、收藏夹、白名单与 GitHub 设置；不增加依赖，不改变站点访问范围。

## 数据与学习闭环

- 分类只允许七个标准分类与“其他”；历史标签在读取时幂等归一化，AI 入库前再次校验。
- 记录统一使用四级 `masteryStage`；历史 `mastery` 仅用于迁移，分数从统计界面移除。
- 增加 `reviewCount`、`reviewLevel`、`nextReviewAt`、`easeFactor`、`skipReason`。
- 固定复习间隔为 1、3、7、15、30、60 天；答对升级，部分掌握保持，答错或跳过回到第 0 级。
- 首页提供“今日待复习”入口；最新一次复习结果决定题目是否仍到期。
- 跳过原因分为太难、不感兴趣、暂时跳过；只有太难是强薄弱信号，连续跳过可降低当前题组难度。

## 可靠性

- AI 错误记录状态、类型、服务商、模型、尝试次数、耗时、上游消息与是否可重试。
- 仅超时、429、5xx、网络与临时解析失败重试；400、401、403、内容拒绝和用户取消不重试。
- 单次题组内连续三次可重试失败后熔断，改用本地题库补足。
- 非空备份不得被空集合覆盖；显式清空必须携带专用授权，页面关闭上传永不携带。
- 旁路备份写前生成 `.bak`，再临时写入并原子替换。
- JSON 是题库唯一真实数据源；Markdown 仅由 JSON 派生，不参与运行时读取。

## 交互与验证

- 支持 Ctrl/Cmd+Enter 提交、左右方向键切题、S 跳过、B 查看最佳回答；输入框、IME、对话框和重复按键受保护。
- 删除所有计时状态、定时器、格式化函数和“用时 00:00”界面。
- 收藏夹不改造，只做回归验证。
- 每项先写失败测试，再实现；完整测试和生产构建通过后同步 GitHub 与 Sites 源码并部署现有站点。
