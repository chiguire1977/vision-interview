# 题组准备状态与 AI 失败诊断设计

## Goal

让开始学习页面准确反映题组准备阶段：联网搜索、AI 请求、重试、题目解析和远程题库同步彼此可区分；AI 题目准备完成后不再等待 GitHub 题库同步才进入答题。

## Behavior

- 专业知识和综合模拟每一轮都保留联网搜索，并在搜索、AI 请求和解析阶段更新同一条准备提示。
- 联网搜索是题源增强环节，不是第三方 AI 出题的硬前置；搜索超时或失败时记录告警并继续请求 AI，且明确告知模型本轮没有可用检索资料。
- 项目答辩继续只使用本地项目资料，不触发专业题联网搜索。
- AI 失败或返回无效题目时，运行日志记录轮次、失败原因、已收集题数和剩余题数，然后继续下一轮。
- 题组最终准备完成或切换本地题库后，界面立即解除“正在准备本题组”；AI 题库 GitHub 同步在后台执行。
- 所有运行日志不记录 API Key、Authorization 或完整回答内容。

## Acceptance criteria

1. 准备提示显示当前阶段和 `第 N/6 轮`，不再只显示固定文案。
2. 每次 AI 请求失败都能在运行日志中找到对应的失败事件和安全错误摘要。
3. AI 题组生成结果返回后，GitHub 同步不会阻塞答题页面解除准备状态。
4. 联网搜索失败时仍会进入 AI 请求阶段，并在提示中显示“继续请求 AI”。
5. 现有题目来源、分类、难度、技术栈筛选和项目答辩隔离测试继续通过。
