# 备份与题组缓存设计

## 目标

修复生产环境未配置 GitHub 写入凭据时右下角持续显示保存异常的问题；将学习记录改为在“学习记录”页面统一手动上传；AI 联网生成题组时先进入远程题库缓存流程，并在远程不可用时保留本地待同步数据。

## 已确认约束

- GitHub 主分支历史必须保留，不能强制覆盖。
- GitHub Token 只从 Sites 服务端环境变量读取，不能写入浏览器、代码或运行日志。
- 启动时继续从远程备份加载学习记录、项目和配置。
- 自动运行备份不再上传 `vision-interview-records`。
- 学习记录上传使用现有 `/api/backup` 合并接口，并以当前浏览器记录集合为该集合的完整快照。
- AI 题组远程缓存继续使用 `/api/question-bank/sync`；远程失败时本地 pending 队列不可丢失。

## 用户体验

- GitHub 写入不可用时，右下角显示“仅本地保存”，不显示红色异常。
- “学习记录”页面显示待上传数量，并提供“上传到 GitHub”按钮。
- 上传成功、失败、待上传数量写入运行日志。
- 题组生成消息明确说明题组已远程缓存或暂存在本地待同步队列。
